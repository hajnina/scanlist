### ag-a6 review fix round 2 (PR #36, REQUEST-CHANGES: quiet hint was unreachable)

**Root cause fixed.** The image source emits one marker per sampled frame (~2.5 fps);
`SignalPool.pushSignal`/`pushImageVector` refresh `lastFiredAt.image` on every one, and
`useScanGuidance` used that stamp as activity, so `quietFor` never crossed 6 s while the camera ran.
A silent/dim scene also does re-render (one marker per frame), contrary to the old doc claim.

**Change (guidance layer only; signal stream untouched).**
- `src/settings/polish.ts`: `quietFor` now takes `ScanProgress` = barcode/OCR/image stamps plus
  `firstFrameAt` and `heroAt`. Frames are proof the camera is delivering; only barcode, OCR text and
  a ranked hero (`topId`) reset the clock. A starting camera (no frame) is still not "nothing found".
- `src/settings/useScanGuidance.ts`: remembers the first frame and the newest hero tick in refs,
  keeps the cleaned-up 1 s interval, and passes those into `quietFor`.
- `src/scan/ui/ScanScreen.tsx`: passes the existing `tick` into the hook (one prop; no pipeline,
  pool or `useScanSession` semantics changed). B4/B6/Kotlin twin see the same signal stream.
- `src/settings/index.ts`: exports the new `ScanProgress` type.
