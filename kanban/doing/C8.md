# C8 — Align C1's OFF proxy with the now-merged S4 contract

## Do
Adversarial review of PR #6 verified these divergences between C1's implemented proxy and the merged
`shared/off/OFF.md` (source of truth):
1. `derive_query_text()` concatenates all four fields including `categories` — OFF.md forbids categories in
   the derived text (provenance/debug only). Rewrite to the S4 derivation: strict `product_name` →
   `generic_name` → brands-concat, NFC, 160-code-point cap, all-empty → `null`.
2. `fields=` must be exactly `code,product_name,brands,generic_name,categories` (C1 omits `code`).
3. `_has_product_content()` counts `categories` → flips real hits into 1-day negative caches. Fix to the
   three derivation fields only.
4. Timeouts: C1 uses 8 s; OFF.md specifies 3 s connect / 10 s total.
5. Cache semantics: adopt OFF.md §cache — positive 30 d / negative 1 d / stale-while-revalidate (MUST serve
   stale on transient failure, `fetchedAt` not extended) / 429 Retry-After / exponential backoff / nothing
   written on transient failure.

the executable contract) and over the recorded fixtures; parity with `python3 shared/off/check_fixtures.py`.

## Notes

### What was done (all five diffs against `shared/off/OFF.md`, card S4)

Read first: `shared/off/OFF.md`, `shared/off/fixtures/cases.json`, `shared/off/check_fixtures.py`.

1. **`derive_query_text()`** — replaced the old "join every non-empty field with `, `" rule with the S4
   algorithm: strict priority `product_name` → `generic_name` → `clean_brands(brands)`, then
   `[:160].rstrip(" ")`, all-empty → `None`. Added `clean()` (NFC, collapse every Unicode `White_Space`
   run — no ZWSP/BOM — strip spaces) and `clean_brands()` (comma split, clean each, casefold-dedupe keeping
   the first spelling, join `", "`). `categories` is never read by the derivation.
2. **`OFF_FIELDS`** — now exactly `code,product_name,brands,generic_name,categories` (was missing `code`).
   Pinned by `tests/test_off_parity.py::test_request_contract_matches_the_spec`, which also compares it with
   `cases.json["fields"]` so the fixture metadata is the source of truth.
3. **`_has_product_content()`** — checks only the three derivation fields; `categories` no longer counts.
   A `200 status: 1` body with no usable name is a **positive 30-day hit with `query_text: null`**
   (previously it was downgraded to `found: false` + 1-day negative caching).
4. **Timeouts** — `CONNECT_TIMEOUT_SECONDS = 3.0`, `READ_TIMEOUT_SECONDS = 10.0` (per-phase caps for
   httpx) plus `TOTAL_TIMEOUT_SECONDS = 10.0` enforced with `asyncio.wait_for` around the whole request, so
   "10 s total" is a real deadline and not just a per-read cap. A timeout is still transient (retried,
   never cached).
5. **Cache semantics** — positive 30 d / negative 1 d; exactly-at-TTL expiry (clock moved backwards = fresh);
   transient failure (5xx, 3xx, non-JSON, connect/DNS/TLS, timeout, 429) writes nothing; expired entry is
   served as `"source": "stale"` without touching `fetchedAt`; 429 records `Retry-After` (seconds or
   HTTP-date, default 60 s) per barcode and refuses to re-ask before it; 5xx/timeout retried 1 s, 2 s
   (capped at 60 s, max 3 attempts); 1,000-entry cap evicting expired then oldest; one in-flight request per
   server (lock) so concurrent ticks share the result.

Files: `apps/web/server/app/off.py`, `apps/web/server/tests/test_off_proxy.py` (rewritten/expanded),
`apps/web/server/tests/test_off_parity.py` (new), `apps/web/server/README.md` (`/off/{barcode}` contract).

### Before / after behaviour (for the PR body)

| situation | before C8 | after C8 |
|---|---|---|
| `product_name` + `generic_name` + `brands` + `categories` all present | `"Nutella, Hazelnut spread with cocoa, Ferrero, Spreads, …"` | `"Nutella"` |
| `categories` present, 3 name fields empty | category text derived, `found` true (1-day cache) | `query_text: null`, still a 30-day positive hit |
| `200 status: 1`, all name fields empty | `found: false`, negative 1-day cache | `found: true`, `product: null`, positive 30-day cache |
| request `fields=` | `product_name,brands,generic_name,categories` | `code,product_name,brands,generic_name,categories` |
| timeout | 8 s per phase | 3 s connect, 10 s total |
| 5xx / timeout | immediate 502, nothing cached | 3 attempts with 1 s/2 s backoff, then 502, nothing cached |
| 429 | 502, no cooldown tracked | `Retry-After` cooldown per barcode; stale text served in the meantime |
| expired entry + OFF down | 502 (cached name lost for the tick) | `"source": "stale"` with the old text, `fetchedAt` unchanged |

No client consumes `/off/{barcode}` yet (`apps/web/` contains only `server/`), so the `found: true` +
`product: null` shape change breaks nothing in-repo.
