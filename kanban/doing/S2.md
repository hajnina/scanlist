What is implemented (spec section → code):

- §2 vectors: `truncate_and_normalize` (first 256 components, float32→float64 widen, then L2;
  norm < 1e-12 → all-zero), zero query → cosine 0.0, NaN/Inf/wrong-dim queries dropped,
  text queries capped at 16 (§2.2). Item vectors are used as supplied (no second normalisation).
- §2.1 `item_vector_cache_key` reproduces the documented SHA-1 material exactly.
- §3 scoring: per-source max of q6(clamped cosine), then max across present sources (never a mean);
  0.15 barcode boost on exact NFC+casefold+whitespace-collapsed name/alias match, before EMA,
  not clipped (raw can reach 1.15).
- §4 EMA: `raw` on first observation, else `q6(0.5*raw + 0.5*prev)`, once per tick;
  checked items carry no state and their old state is dropped.
- §5/§6: q6 half-away-from-zero everywhere, ties by `order`, hysteresis strictly `> 0.02`,
  entries = sticky top, then sorted candidates, then done group in flatten order, `topId`.
- §7: `RankTicker` enforces one evaluation per `MIN_INTERVAL_MS = 400` (`tick` returns `None`
  inside the window), `tick_now` for tick/untick and it resets the clock, `list_changed` /
  `scan_started` clear state + top, `scan_stopped` returns the unranked output.
- §8: no signal → unranked flatten order + cleared state; all checked/empty list → ranked,
  `topId=null`; missing/wrong-dim/NaN item vector → previous output returned with state
  untouched (caller passes `prev_output`; first tick = unranked); stale/removed ids are dropped
  from state.
- FLATTEN.md: depth-first items-before-sub-sections traversal, explicit/derived ids
  (`sha1:` + SHA-1, `#index`), `~2` collision renaming, alias trim/dedupe (NFC+casefold),
  amount/unit/note normalisation, `docText` = `name; aliases; path` (notes excluded).
