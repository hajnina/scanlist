### What was done

- Recorded **19 real OFF API v2 responses** with `curl` on 2026-11-16 against
  `https://world.openfoodfacts.org/api/v2/product/<barcode>.json?fields=code,product_name,brands,generic_name,categories`
  and `User-Agent: ScanList/0.1` (17 hits, 2 real misses: `3245390098214` plain 404 and
  `3560070829668` 404 `status: 0` whose `status_verbose` misleadingly says "product found with a
  different product type: petfood"). Files are byte-for-byte the received bodies
  (`cmp` against the raw curl output for a sample; no pretty-printing/wrapping).
  Barcodes used: 3017620422003, 3017620425035, 3229820129488, 3168930010265, 3560070976478,
  5000159484695, 5449000000996, 7622210449283, 7622300336738, 8000500310427, 8076800195057,
  2000000000005, 3560071011956 (brands-only), 0202075011817 (empty name strings + leading-zero
  barcode), 3560070813704 (91-char name), 7640112099009 (triple space), 8593807234713 (double space,
  Czech), 3245390098214 (404), 3560070829668 (404).
- Wrote `shared/off/OFF.md`: request contract (host, `fields=`, UA, barcode regex `^[0-9]{8,14}$`,
  timeouts/redirects, outcome table), normative derivation (`clean` = NFC + White_Space run collapse +
  strip; priority `product_name` > `generic_name` > `clean_brands(brands)` > null; no concatenation
  across name fields; comma-split brands, casefold dedupe, join `", "`; hard 160-code-point cap),
  14 worked examples (12 real fixtures + 2 synthetic), cache rules (positive **30 days**, negative
  **1 day**, transient failures uncached, stale-while-revalidate without extending `fetchedAt`,
  single-flight, LRU cap), OFF etiquette/licensing (≤100 product req/min, `Retry-After`, no search
  API for lookups, no bulk, ODbL attribution), and the barcode-exact-match boost contract (the
  compared string is the same derived text; `norm` = NFC → casefold → whitespace-run collapse → trim;
  exact equality vs name/aliases only, +0.15 on `raw` before EMA).
- Added `shared/off/fixtures/cases.json` (request provenance: URL, HTTP status, UTC fetchedAt,
  outcome, hand-written `expectedQueryText` and `why`) plus `boostCases` (10) and `normCases` (5).
- Added `shared/off/check_fixtures.py` (stdlib only, no network): derives each fixture's query text,
  checks it against `cases.json`, checks hit/miss vs HTTP/status, checks orphan fixture files, and
  runs the boost/norm cases.

### Decisions / notes for reviewers

- `product_name` is never concatenated with `generic_name`/`brands` (card asked which field wins);
  brands are only a last-resort fallback and are concatenated per `clean_brands`.
- Fixtures store the **raw** derived text; the `prompts.json` query prefix is added by the embedder at
  runtime and is not part of the OFF cache. B5/A5/C5 can share these fixtures regardless of the S3
  prefix decision.
- OFF search endpoints (`/api/v2/search`, `/cgi/search.pl`) returned **HTTP 503 HTML** while recording
  (product endpoint stayed healthy); this is documented as a real etiquette reason not to use search
  for barcode lookups.
- Coverage gap: no real fixture has `generic_name` without `product_name`, or all three name fields
  empty; both are covered by the normative rules + synthetic examples. No fixture exceeds 160 code
  points (longest real name is 91), so truncation is unit-test territory.
- No Android/Kotlin/TS code or `.github/` touched, so this PR should not affect the CI APK build; no
  local build needed for docs/fixtures/stdlib script.
