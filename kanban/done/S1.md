### Decisions (reviewable)

1. **q6 rounding** (`round-half-away-from-zero` at 6 dp) is applied to every stored/compared score; it makes
   numpy vs JS float noise irrelevant and the hysteresis boundary exact. Card only said "ties keep JSON order";
   this defines the tie and the > 0.02 comparison precisely.
2. **Derived ids are namespaced** `sha1:<40 hex>` (card says "sha1 of section/path/name#index"); bare explicit
   ids stay verbatim; deterministic collision renaming `base~2`, `base~3`… so ids are always unique.
3. **`prompts.json` sets are top-level keys** (`mnemothera`, `modelcard`) next to `active`, matching the card
   wording literally; S3 only has to change `active`.
4. `docText` order is `name; aliases; full section path` exactly as `docs/ARCHITECTURE.md`; `note` and
   amount/unit are excluded from embeddings.
5. Hysteresis is sticky regardless of how long the current top has been top (no time decay); scan stop/no
   signal clears state and returns unranked JSON order.
6. Image query window: up to 4 newest image vectors from the last 2000 ms; at most 16 text queries per tick
   (barcode + OCR lines). These are caller-side bounds for library parity.
