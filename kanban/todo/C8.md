# C8 — Align C1's OFF proxy with the now-merged S4 contract

## Do
Adversarial review of PR #6 verified these divergences between C1's implemented proxy and the merged
`shared/off/OFF.md` (source of truth):
1. `derive_query_text()` concatenates all four fields including `categories` — OFF.md forbids categories in
   the derived text (provenance/debug only). Rewrite to the S4 derivation: strict `product_name` →
   `generic_name` → brands-concat, NFC, 160-code-point cap, all-empty → `null`.
2. `fields=` must be exactly `code,product_name,brands,generic_name,categories` (C1 omits `code`).
3. `_has_product_content()` counts `categories` → flips real hits into 1-day negative caches. Fix to the
   three derivation fields only.
4. Timeouts: C1 uses 8 s; OFF.md specifies 3 s connect / 10 s total.
5. Cache semantics: adopt OFF.md §cache — positive 30 d / negative 1 d / stale-while-revalidate (MUST serve
   stale on transient failure, `fetchedAt` not extended) / 429 Retry-After / exponential backoff / nothing
   written on transient failure.
Add tests: run the derivation over `shared/off/fixtures/cases.json` expected values (the checker's cases are
the executable contract) and over the recorded fixtures; parity with `python3 shared/off/check_fixtures.py`.
