# S10 — Margin rule + no-match threshold (post-S3 calibration)

## Do
Evidence (premortem + camera-prior-art research, 2026-11-16): a plain score threshold is the wrong primitive for
the highlight decision; the missing piece is a MARGIN rule, and "no match on screen" must be detectable. Using the
numbers S3 measured in shared/fixtures/PREFIX_AB.md (top1/top2 score distributions on golden queries AND on the
'not on the list' distractor queries):
1. Amend `shared/spec/RANK.md`: the top item is only highlighted when `smoothed_top1 − smoothed_top2 ≥ M` (start
   from M = 0.05, the value the Smart-Fridge pipeline converged on) AND `smoothed_top1 ≥ T_no_match` (choose T from
   the distractor score distribution so distractors stay un-highlighted; document how you picked it). Otherwise the
   list shows ranked order with NO hero highlight. Keep EMA α and hysteresis as v1 defaults (X1 bench revises).
   ALSO (review finding 2026-11-16): `norm()` in RANK §3.1 uses `casefold()` which Kotlin/TS/JS lack — add one
   sentence requiring Unicode FULL case folding (CaseFolding.txt, C+S+F mappings) so all three tracks implement
   it identically (S4's OFF.md §6 now carries the same note).
2. **SOURCE-SPECIFIC RULES (S3 data, corrected during its adversarial review — PR #13):** the TEXT gate
   (top1 ≥ T_text AND top1−top2 ≥ 0.05) kept 30/31 hits, all 12 text distractors below it (max margin 0.043) —
   sound. The IMAGE gate (top1 ≥ 0.68 AND margin ≥ 0.005) does NOT suffice alone: it keeps 10/13 correct,
   suppresses 2 (fail-safe) AND produces 1 FALSE HIGHLIGHT — cheese.jpg → Greek yoghurt (raw 0.699, margin
   0.025, dominating butter's 0.0074 in both dims; unfixable by threshold tuning on this fixture). RANK.md must
   specify an image-side guard BEYOND the margin gate — evaluate at minimum: (a) an accept-list stage (barcode /
   OFF name match overrides the gate), (b) a second-stage re-embed (e.g. best crop / multiple frames must agree,
   Smart-Fridge's one-decision-per-pass pattern), (c) requiring the winner to also beat the best TEXT score when
   a text source is present this tick (fusion-aware gating). Pick ONE for v1 (document why in RANK.md), keep
   golden.json expected top-3 unchanged, and add golden test cases: cheese.jpg must NOT highlight, eggs.jpg /
   bread.jpg stay suppressed (fail-safe is correct behaviour).
2. Update the reference ranker (shared/ref/scanlist_ref.py) + its tests, and shared/ts-core's rank, to implement
   margin + no-match threshold; keep golden.json expected top-3 outputs unchanged (ranking order does not change —
   only the highlight decision does). Add golden test cases: a distractor query must produce no highlight.
3. Note in prompts.json nothing changes (prefixes stay as S3 set them).
